Build a contacts API, step by step

An interactive guide. Pick your language, framework and storage on each page and the code changes to match. Work through the parts in order.

  1. Part 1: build it (steps 0 to 9)
    Design, folders, database, create/read/update/delete, safety, frontend, accounts, docs.
  2. Part 2: harden it and run it (steps 10 to 16)
    Redis, sessions, CORS, logs, caching, audit log, email, deployment.
  3. Part 3: more tables and live features (steps 17 to 21)
    Companies and tags, metrics, webhooks, WebSockets, and other topics.
